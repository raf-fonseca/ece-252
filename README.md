## Lab 1

In this lab, you will create two command-line tools:

1.  **`findpng`**: A tool to search a given directory hierarchy to find all valid PNG files within it.
2.  **`catpng`**: An image data concatenation tool to combine the pixel data from a set of PNG files into a single PNG image.
    * **Note**: `catpng` will only process PNG images that share the same width.
